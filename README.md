# 出社會該學習的事情

一個職場觀察筆記系列。從日常生活的小場景出發，對照職場上反覆出現的問題，提煉出能帶走的原則。

不是教學文，是把自己這些年走過的彎路、看過的場景，整理成下一個人可以少走一點的提醒。

## 寫作格式

每篇文章採三段式結構:

1. **生活故事** — 一個具體的場景
2. **職場對照** — 同樣的模式在工作裡怎麼出現
3. **提煉原則** — 一句話能帶走的提醒

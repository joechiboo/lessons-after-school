# 出社會該學習的事情

一個職場觀察筆記系列。從日常生活的小場景出發，對照職場上反覆出現的問題，提煉出能帶走的原則。

不是教學文，是把自己這些年走過的彎路、看過的場景，整理成下一個人可以少走一點的提醒。

## 文章目錄

1. [第一課：Call help 的能力 ——公園裡的管理課](posts/01-call-help.md)
2. [第二課：不要每件事都問，要先歸納彙總](posts/02-summarize-before-asking.md)
3. [第三課：抓重點 ——講重點](posts/03-get-to-the-point.md)

## 寫作格式

每篇文章採三段式結構:

1. **生活故事** — 一個具體的場景
2. **職場對照** — 同樣的模式在工作裡怎麼出現
3. **提煉原則** — 一句話能帶走的提醒
